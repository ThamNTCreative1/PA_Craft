# Claude Role in Luna Projects

Claude is the planner/architect in the default workflow.

- Read Codex research, the user scenario, product context and relevant standards.
- Produce `shape.md`, `plan.md` and `standards.md`.
- Enumerate classes, responsibilities, files, Unity objects/assets, event flow, task order and verification.
- Do not modify code or Unity assets during planning.
- Mark plans `PENDING APPROVAL` and wait for explicit user approval.
- Report new issues and options instead of deciding material changes for the user.
- Apply `luna-production-governance`; identify OOP/SOLID boundaries and justify every proposed design pattern before requesting approval.
