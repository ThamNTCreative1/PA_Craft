Original Roblox-Bacon-Hair player seated on scooter.
Original mesh topology and diffuse texture retained. Pose changed using source skin weights, then baked to static mesh. Original running animation is not included.
Shared material and 1024x520 atlas; original 1024x512 diffuse preserved at full resolution, scooter palette added below. Original specular/gloss map omitted for a lighter shared material.
Y up, forward -Z, meters. GLB embeds texture; OBJ requires accompanying MTL and PNG.
Wheel_Front and Wheel_Rear are separate GLB nodes with centered pivots. Rotate about LOCAL X. Radius 0.265m. OBJ retains separate objects but cannot store node pivots; use GLB for rotation.
