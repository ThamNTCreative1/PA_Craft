# Luna Project Agent Rules

- Follow `agent-os/workflows/codex-claude-codex.md`.
- Codex analyzes first, Claude plans, the user approves, then Codex implements.
- No project mutation is authorized by a research or planning request.
- Before implementation, present the class/interface/file/scene/prefab list and verification plan.
- Stop and report unexpected issues with cause, impact and options; wait for user approval before changing the approved solution.
- Reuse from another project means logic only. The user must first confirm the identified source logic.
- Apply the standards indexed by `agent-os/standards/index.yml`.
- Apply the `luna-production-governance` skill to planning, implementation, review and asset work.
- Load the specialized Luna skill selected by the governance router; architecture and verification are mandatory for implementation plans.
- Blender MCP belongs to Codex only. Claude plans Blender work; Codex performs approved Blender changes and verifies tris/export/size constraints.
